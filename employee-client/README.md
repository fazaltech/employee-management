# PeopleOps Angular client

Angular 22 standalone frontend for the Employee Management solution.

Use Node.js 24.15.0 (see `.nvmrc`), install packages with `npm install`, and start the development server with `npm start`. The client runs at `http://localhost:4200` and calls the API at `http://localhost:5286/api`.

See the repository-level `README.md` for full setup, MongoDB, API, testing, and configuration instructions.
